# D&G Global株式会社 ヒーローのデザイン意図

現行ページはD&Z Global 株式会社の1ページ企業サイトに再構成済み。ヒーローは社名の「&」と大きなタイポグラフィを使用している。[現在の構成と意図](corporate-onepage.md)を参照。以下は以前の曲面画像の意図の記録であり、現在の造形・事業内容を示すものではない。

## デザインコンセプト

**違いをつなぎ、人と企業の可能性をひらく。**

これはユーザーが共有した事業をもとにしたデザイン上の解釈であり、会社の正式な理念として確定した文言ではない。

共有された事業は、通訳・商業展示会等の同時通訳、取引先従業員への言語指導、グローバル人材育成、コンサルティング。デザインでは、通訳によって意思疎通を支えることと、教育によって人が活動できる可能性を広げることを共通の軸として捉える。

## 画像の形を選ぶ理由

### 複数の面 — 異なる背景を持つ人や企業

向きや起伏の違う面を、人や企業が持つ言葉・文化・考え方の違いに重ねる。同じ白系の素材を使い、色による国別・属性別の分類や優劣はつくらない。

### 面が接する場所 — 通訳や支援が担う接点

面が近づき、接し、その先へ続く構図を、理解や関係が生まれる接点として位置づける。深い影は立体の接点を見せるために限定して使う。壁・断絶・閉じた穴を主役にしない。

### 接点から開く明るい空間 — 育成が支える可能性

接点の先に、余白と明るい面が続く構図を選ぶ。目の前の意思疎通と、その後に人が力を発揮する可能性を、一つの空間の中で関連づける。

輪郭を画面の外まで続かせ、特定の国や土地の図柄を使わず、関係や活動が広がっていく印象を目指す。

## 色と質感の理由

- 青みの白 `#F4F8FA`: 開放感、相手を受け入れる余白、コピーの読みやすさ。
- 青みの黒 `#081824`: 法人向けの落ち着き、情報の明瞭さ、接点の立体感。
- マットな質感と穏やかな陰影: 人材育成や言語支援に合う、落ち着いて話せる印象を目指す。

色の選択にはユーザーの好みが含まれる。形と構図の選択は上記の事業コンセプトに基づく。配色だけを事業との関連の根拠にしない。

## 画像・コピー・導線の役割

画像は「違いが接し、その先へ可能性が広がる」という抽象的なブランドイメージを担う。

メインコピー「言葉を越えて、可能性をひらく。」では、前半を通訳・コミュニケーション支援、後半を語学指導・人材育成につなげる。

補足コピーで「通訳・語学指導・グローバル人材育成」と事業を具体的に示し、「事業内容を見る」へ案内する。コピーを置く左下を明るく低コントラストにして、画像の接点から続く余白に言葉を載せる構成とする。

## 抽象表現の限界

この画像だけで通訳や人材育成の会社だと判別できるわけではなく、他業種にも使える造形である。形に意味を割り当てただけで独自性や理解が保証されるものではない。

ヒーローは画像・コピー・会社名を合わせて評価する。画像単独に事業説明の責任を負わせず、事業の具体性は本文で明示する。

## 今後の選定基準

1. 異なる面が見分けられ、接点と開いた余白の関係がある。
2. 暗い閉塞感より、明るい開放感が主役になる。
3. 形の複雑さがコピーや事業理解を妨げない。
4. 人物・機器・地球等を追加せず、ユーザーが好む抽象表現を維持する。
5. 構図の採用理由を、配色の好みだけでなく上記のコンセプトから説明できる。
