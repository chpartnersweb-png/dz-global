# 大小の色面から球面へ移るヒーロー

## 依頼と構成

ユーザーが示した https://www.rgf-professional.jp/ の、写真が空間に広がった状態から球面にまとまり、右側に寄って次のセクションへつながる動きを参考にした。参照サイトの写真やコードは使用していない。

現在の大きな「&」を残し、画像の代わりにサイトのネイビー `#2B405F` と白 `#FFFFFF` を使った大小の矩形面を独自に描画する。

1. ヒーロー：大小・濃淡の異なる面が、奥行きのある空間に広がる。
2. 下へスクロール：面の位置・向き・大きさが球面の配置へ補間される。
3. ABOUTへ：球体が右側に寄り、本文が左側に続く。濃紺の背景上では面の色を白系に切り替える。
4. 上へスクロール：逆方向に配置が戻る。

## 編集元

- `src/components/HeroStory.astro`：共通レイヤーとCSSによる静的フォールバック
- `src/components/CorporateHero.astro`：既存のコピーと大きな「&」
- `src/components/AboutSection.astro`：既存のABOUT本文
- `src/scripts/hero-tiles.ts`：Three.jsの描画とScrollTrigger
- `src/styles/home.scss`：重なり順、sticky、ABOUTの配置
- `src/scripts/motion.ts`：初期化・終了処理

ヒーローは引き続き表示領域の高さを基準とする。描画レイヤーはヒーローとABOUTの範囲だけstickyで表示し、その後の事業紹介などには重ならない。大きな「&」の要素・書体・サイズ・線の色は維持する。

## 描画と動き

Three.jsは必要時に動的に読み込む。初期画面幅に応じてPC156面、スマホ90面をInstancedMeshで描画する。乱数の種を固定し、再読み込みで構図が無秩序に変わらないようにしている。点描の粒子や写真テクスチャは使用しない。

スクロール区間はヒーローの高さの約1.1倍。ScrollTriggerのscrubで、散在・球面の変形と右への移動を進める。背景にはゆっくりした漂いと回転も加える。文字の実際の位置をもとに描画を薄くし、PCではABOUT本文を左側にまとめる。スマホでは本文を1列に保ち、球体は右側へ逃がす。

画面幅・高さの変更でカメラと描画サイズを更新。画面外・タブ非表示・メニュー表示中は描画を休止する。動きを減らす設定ではThree.jsを起動せず、静的な色面と既存の「&」を表示。WebGLを初期化できない場合も静的表示を維持する。終了時はticker、ScrollTrigger、監視処理、GPUリソースを解放する。
