# ヒーロー — 面と光の重なり

更新日: 2026-11-04（日本時間）

## 依頼と変更範囲

ユーザーの「ヘッダーは現状のまま」「粒子が気持ち悪いという意見もありそうなのでヒーローのデザイン・背景を変更したい」に対応。

SiteHeader.astro、ヘッダー用のCSS、共通の配色・フォントは変更していない。ヒーローの背景・文字組み・導線と、その登場演出を変更した。

## デザイン

青みの白 `#F1F6FC` を中心に、青みの黒 `#0A2035` の低い不透明度で、大きな面と穏やかな光の重なりを構成する。異なる方向から広がる面が一つの空間で重なることを、異なる背景の人や考え方の交わりに重ねる。

密集する粒、細かな反復模様、人物・地球・機器、膨らんだ曲面の狭い合わせ目は使わない。背景の要素数を2つの大きな面と広い光に絞り、コピーと余白を主役にする。

メインコピー「言葉を越えて、可能性をひらく。」と事業説明を中央配置にした。主導線は青みの黒の長方形ボタン。上部の細かな補助ラベルとフッターの重複する社名表記を整理した。

## 実装

- Hero.astroから粒子スクリプト、参照画像、canvas、背景の停止ボタンを外した。
- 背景はCSSのclip-pathとグラデーションで描くため、画像読み込みやWebGLの起動を必要としない。
- GSAPで面とコピーの短い登場演出を行う。継続的な背景アニメーションは設けない。
- Lenisと既存のヘッダーのスクロール制御は継続する。
- PC・タブレット・スマートフォンで中央配置を保ち、背景はヒーロー全面に表示する構成。
- 過去の粒子コードと画像は履歴として残しているが、現在のヒーローからは読み込まない。

## 確認範囲

これまでのユーザー指定に従い、今回も実装後のビルド・型チェック・ブラウザー確認・テストは行っていない。
