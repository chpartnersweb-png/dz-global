# Three.jsヒーロー — 交わり、広がる粒子

実装日: 2026-11-04（日本時間）

## 参照とデザイン意図

ユーザーが添付した `ChatGPT 画像 2026年11月4日 17_51_34.png` の粒子表現をもとに実装。

細かな粒が複数の方向から重なり、奥行きのある空間へ続く表現。個々の粒を異なる人や考え方に、混ざり合う集まりを交流に重ねる。人物・地球・機器を直接描かずに、人と人とのつながりや広がりを表すという依頼に対応するデザイン上の解釈。

配色は、追加の「もう少し青っぽく」という指定を反映し、青みの白 `#F1F6FC` と青みの黒 `#0A2035` に変更。具体的な事業名は既存のHTMLコピーで伝える。

## 構成

- `src/assets/images/hero-particles-reference-v1.png`: 添付画像をそのまま複製した参照画像。元ファイルは変更していない。
- `src/components/Hero.astro`: WebP化した静止画像、canvas、コピー、停止・再生ボタン、3D初期化を担当。
- `src/scripts/hero-particles.ts`: Three.jsのPointsとShaderMaterialで粒子を描画。
- `src/styles/global.scss`: canvasと静止画像の切り替え、静止画像のコピー周辺を薄くするマスク、操作ボタンのレイアウト。

## 参照画像からの粒子生成

表示用画像を一時的なcanvasへ縮小描画し、濃淡を読み取る。暗い場所ほど粒子が集まりやすい重みとして使い、参照画像の大きな流れと密度分布に近づける。

各粒にランダムな奥行き・大きさ・濃さ・動きの位相を割り当てる。手前と奥の粒はサイズと透明度を変えた柔らかな点、中央付近は小さく輪郭のある点にし、被写界深度に似た見え方をシェーダーで近似する。参照画像の画素をそのまま立体化するものではなく、分布を参照した動く粒子の再構成。

画像のピクセル読み取りが利用できない場合や、WebGL・シェーダーを初期化できない場合は、静止画像を継続表示する。

## 動きとレスポンシブ

- 粒子ごとの小さな揺れと、全体でつながる穏やかな流れをGPU上で計算。
- PCではマウスに合わせて視点をわずかに変化させる。
- スクロールに合わせて粒子の流れを少し上へ移動。
- コピーの実際の表示範囲を測り、その周辺だけ粒子の透明度を抑える。下半分や左下全体を薄くする処理は外した。ヘッダーとフッターも必要な範囲に限って薄くする。
- PCは最大90,000粒、中間サイズは52,000粒、幅768px未満は22,000粒。
- 描画頻度はPCが最大45fps相当、スマートフォンが最大30fps相当。ピクセル比の上限はPC1.5、スマートフォン1。
- 全デバイスで粒子をヒーローの上下いっぱいに配置する。縦画面で高さを圧縮して上へ移動する旧設定を廃止。背景のcanvasもヒーロー全面を覆う。
- 「動きを止める／動きを再生する」を用意。動きを減らす設定では静止した粒子を描画。
- ヒーローが画面外、タブが非表示、メニュー表示中は連続描画を休止。
- 既存のGSAP tickerを共用し、別の継続的なrequestAnimationFrameループは作らない。
- リサイズ・WebGLコンテキスト喪失／復旧・HMRの破棄時のイベントとGPUリソース解放に対応。

## 全面表示・配色の追加調整

「タブレット以下やスマホサイズでも全体に表示」「サイト全体をもう少し青っぽく」という依頼に対応。

- 旧設定は縦画面で粒子の高さを46%または64%に圧縮し、上方へ移動していた。全画面で高さ108%の分布と中央配置に揃えた。
- コピーの位置・幅・高さをシェーダーに渡し、その範囲だけ粒子を薄くする。リサイズ時とフォント読み込み後に範囲を更新。
- 静止背景のマスクも同じコピー位置に追従する。静止画像はluminosityの合成で背景の青みと馴染ませる。
- 共通SCSSの2色、Three.jsの代替色、ブラウザーのテーマカラー、ファビコンを新しい配色に揃えた。
- 全面表示による粒子の背景上でも読めるよう、停止ボタンに同系色の薄い背景を追加。

この追加調整後も、ユーザー指定に従いビルド・ブラウザー等の確認は行っていない。
