# ヒーロー — 白いレリーフ

更新日: 2026-11-04（日本時間）

## デザイン

ユーザーの「何かデザイン変なので、別のデザインで実装してください」に対応し、浮遊する線のまとまりから、白い面の大きな起伏と光・陰影を主役にしたレリーフ表現へ変更。

青みの白 `#F4F8FA` と青みの黒 `#081824` を継続。白い面の開いた等高線状の起伏が、上部から右側へ広がる。輪郭は画面の外へ続き、地球・球体・地図を使わずスケールを表現する。

## 実装

- `src/scripts/hero-relief.ts` でThree.jsを動的に読み込む。
- 全面のPlaneGeometryとShaderMaterialを使い、仮想的な高さの場から法線・光の反射・谷の陰影を計算する。多数の線や浮遊オブジェクトは表示しない。
- 時間とともに起伏の位相がごくゆっくり変わる。PCではマウスに合わせて光の向きと表面の位置が少し変わる。
- コピー、ヘッダー、フッター付近では陰影を抑える構成。
- 背景の停止・再生、動きを減らす設定、メニュー表示・画面外・タブ非表示時の描画休止を継続。
- GSAPのtickerを共用。スマートフォンは最大24fps相当・ピクセル比1、PCは最大45fps相当・ピクセル比1.5を上限とする。
- 静止代替表示は `public/hero-relief-fallback.svg`。曲面と陰影を表すコードで作成したベクターであり、今回AI画像生成は使用していない。
- 旧案のスクリプトとSVGは履歴として残しているが、Hero.astroからの参照は外している。
