## 開発

```sh
npm run dev
npm run astro -- dev status
npm run astro -- dev logs
npm run astro -- dev stop
```

devスクリプトは `astro dev --background` に相当し、AGENTS.mdの指定に従う。プロジェクト名の `&` を含むWindowsパスに対応するため、npmスクリプトからAstroのNodeエントリーポイントを呼ぶ。
